# Разработка мобильных приложений — лабораторная работа 3

**Тема:** Работа с сетью

Необходимо разработать мобильное приложение под Android, которое демонстрирует авторизованному пользователю набор данных в соответствии с выбранной предметной областью. Данные должны получаться через интернет-соединение и сохраняться в резервное хранилище для последующего использования без доступа к интернету.

Лабораторная работа 3. Работа с сетью 
Необходимо разработать мобильное приложение под операционную 
систему Android, которое демонстрирует авторизованному пользователю 
набор данных (в соответствии с выбранной предметной областью), 
получаемых через интернет соединение (и сохраняемых в резервное 
хранилище для последующего использования вне интернет доступа). 
 
1. Постановка задачи 
В рамках данной лабораторной работы необходимо добавить 
разрешение на сетевой обмен, имплементировать один из сетевых клиентов 
(на выбор студента) и реализовать запросы на получение данных с 
выбранного REST API. Необходимо запрашивать не все данные с сервера, а 
блоками (страницами или заданным количеством объектов). 
 
1.1. Добавьте разрешения на обмен данными через интернет 
в файле AndroidManifest вашего приложения 
<uses-permission android:name="android.permission.INTERNET" /> 
<uses-permission 
android:name="android.permission.ACCESS_NETWORK_STATE" /> 
 
1.2. Имплементация клиента сетевого взаимодействия 
Выберите один из HTTP клиентов – Ktor Client (для kotlin) или Retrofit 
(допускаются оба языка) для которого необходимо: 
• Добавить зависимости для выбранного вами  сетевого клиента (и 
соответствующие инструменты или плагины для сериализации 
данных); 
• Создайте классы -модели для десериализации JSON ответов от 
сервера; 
• Реализуйте репозиторий (или сервис) для подключения сетевого 
клиента и выполнения запросов на сервер, ожидающих некоторое 
количество данных (порцию). Желательно заложить возможность 
получения следующей порции данных (постранично, заданное 
количество со сдв игом или иное в зависимости от выбранного 
REST API);

2. Подключение клиента сетевого взаимодействия 
2.1. Для проектов с Ktor Client 
https:/ /ktor.io/ (https:/ /ktor.io/docs/http-client-engines.html) 
Помимо зависимостей самого HTTP клиента, включите Kotlinx 
Serialization plugin в файле build.gradle (Module): 
https:/ /github.com/Kotlin/kotlinx.serialization 
 
2.2. Для проектов с Retrofit 
https:/ /lysine.dev/retrofit/ (бывш. https:/ /square.github.io/retrofit/) 
Помимо зависимостей самого HTTP клиента, также нужно подключить 
конвертер JSON-данных на ваш выбор . Н апример, библиотеку GSON 
https:/ /github.com/google/gson  
 
2.3. Для проектов с XML 
Для отображения списка данных используйте RecyclerView 
https:/ /developer.android.com/develop/ui/views/layout/recyclerview  
Не забудьте использовать инструмент View Binding вместо вызова 
findViewById() в адаптере, размещающем полученные данные в 
RecyclerView
